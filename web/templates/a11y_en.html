Accessibility statement

This statement applies to this instance of Dudle-NG (scheduling and polls). Last updated: 18 November 2026.

Conformance status

The goal is conformance with the Web Content Accessibility Guidelines (WCAG) 2.1, level AA. For public bodies in North Rhine-Westphalia this follows from the Disability Equality Act NRW (BGG NRW) and the accessible IT regulation BITV NRW, which refer to the European standard EN 301 549.

No independent audit by an external body has taken place so far. By our own assessment, this website is partially conformant.

How it was tested

  • Automated checks with axe-core (rules for WCAG 2.0, 2.1 and 2.2, levels A and AA) in the light and dark colour schemes, for the start page, poll, edit and delete views, management page, error page, and in German and Arabic.
  • Manual checks of keyboard-only operation and of the layout at a narrow width (320 pixels).
  • Tests with screen readers (for example NVDA, JAWS or VoiceOver) have not been carried out yet.

Measures taken

  • All functions can be used with the keyboard, the focus is clearly visible, and there is a “Skip to content” link.
  • Text has a contrast of at least 4.5 : 1 (large text and controls 3 : 1) in both colour schemes. The scheme follows the operating system setting.
  • Voting results are not conveyed by colour alone, but also by symbols and text.
  • Form fields have labels; error messages appear as text and are announced to assistive technology.
  • The page language and individual language links are marked up. Arabic and Hebrew are displayed right to left.
  • Text can be enlarged and the layout adapts to small screens. Motion is reduced when the operating system asks for it.
  • The core functions (creating a poll, voting) also work without JavaScript.

Known limitations

  • The translations into the additional languages were produced by machine and have not been reviewed by native speakers.
  • The calendar date picker is optimised for mouse and touch; it can be operated with the keyboard but is less convenient than a standard date field. Without JavaScript, plain date fields are used.
  • The voting table of polls with many options scrolls horizontally inside the table.
  • There is no content in plain language and no sign-language video.
  • The CSV export and Atom feed are not web pages and have not been checked for accessibility.
